# 给小天使磕一个

一个竖屏的小祈愿页：轻点小天使的小脑袋或整个头像，就会磕一下，下面显示累计求数与今日已求。

## 本地预览

```powershell
python -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。本地预览使用独立的开发计数命名空间，不会影响线上的数字。

## 计数方式

- 累计求数与今日已求是全站共享的，所有打开链接的人一起计数。
- 今日按北京时间（Asia/Shanghai）在每天 00:00 归零。
- 计数通过 [Abacus](https://abacus.jasoncameron.dev) 的公开计数接口完成；接口暂时不可用时，数字会先记在当前浏览器里，恢复网络后继续同步。
- 页面也会在 `localStorage` 留一份缓存，断网时仍然能显示与累加。

## 部署

纯静态站点，直接由 GitHub Pages 托管，不需要构建步骤。

## 说明

头像由站点主人提供。页面不使用 Cookie，不收集个人信息。
